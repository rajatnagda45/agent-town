## Capture checklist

- Show only approved demonstration data; hide tokens, private conversations and account details before recording.
- Use 16:9 desktop framing; keep IDs, result and source text legible. Show date and label a prior run as recorded.
- Capture an uninterrupted task-ID-before/reload/task-ID-after segment. Keep the source take and disclose cuts that compress waiting.
- If creating a fresh execution, obtain provider budget authorization first; retain failed attempts and the actual result. Never rerun silently until the model says what the script expects.
- Record narration and screen locally, review the full export, then obtain publication authorization and check the final link in a signed-out browser.
- If the provider fails, show its error briefly and use the labelled historical core recording/evidence. This is a fallback presentation, not a passing live sponsor submission.
- Leave voice out of the critical path until physical microphone and speaker acceptance passes.
